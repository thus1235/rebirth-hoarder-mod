# 末世：我有一辆房车 —— MOD 工具库 (Rebirth Hoarder Mod & Save Editor)

《末世：我有一辆房车》(Rebirth Hoarder, Steam/Electron, **版本 3.11，2026-09-05**) 的第三方单机增强工具：

- **游戏内修改面板**（F8 开关，可小型化）：战斗秒杀 / 解锁楼层（全部、到指定层）/ **还原楼层（真实进度，指定层数）** / 跳层 / 强制撤离 / 一键生态打理。
- **存档修改器**（独立 exe）：修改源晶、现金、角色属性、装备、卡牌、命途、医疗舱、物品数量等。

> 适配游戏版本：app.asar = **1461942822** 字节（2026-09-04 起的最新版）。

## ⚙️ 安装（分发包 `mod/`）

### MOD 增强（游戏内 F8 面板）

1. 完全关闭游戏。
2. 双击 `安装MOD.bat`（自动定位正式版/副本游戏目录；找不到时手动输入）。
3. 启动游戏 → 进废墟探索 → 按 **F8** 打开面板（再按一次 F8 或点 ✕ 关闭）。

**还原原版：** 双击 `还原MOD.bat`。

> 游戏更新导致 MOD 失效时，重跑 `安装MOD.bat` 会询问后自动清理并重装，无需先还原。

### 存档修改器

1. 双击 `存档修改器.exe`（游戏开着也能改）。
2. 自动读取存档目录。
3. 修改数值 → 点「写入修改」（写入前自动备份 + revision 比对 + 自动重算校验和）。

## ✨ 功能清单（F8 面板 v1.8）

**战斗**
- ⚡ 当前战斗直接胜利
- 🎯 自动秒杀模式（开关）
- 自动领奖：普通/精英战胜利自动全收战利品；守关 BOSS（每 10 层）保留原版「三选一」，不卡死

**楼层（废墟探索）**
- 🔓 一键解锁全部楼层（本次启动游戏内有效，重启自动恢复原状）
- 🔓 **解锁到指定楼层**：输入框填楼层号（如 30），只解锁到该区域第 N 层
- ↩️ **仅还原MOD解锁**：撤销上面的 MOD 解锁标志，不改动真实进度
- 📉 **还原已解锁楼层到指定层数**：**改写真实楼层进度**（含自己一层层打上去的），
  填 N 降到第 N 层、填 0 清空该区域；执行前自动撤本局 MOD 解锁，10/20/30… 的
  boss 检查点层同步回落锁定；需点两次确认（防误触），游戏自动存档后生效
- 🔼 跳到当前区域最高层（与解锁配合可一步直达区域顶楼）
- 🚪 强制撤离当前区域（弹出撤离确认界面，可打包物资，带出掉落）
- 已内置：楼层自由选择（无需定位器）/ 默认选中最高已解锁楼层 / 去掉 100 层上限

**生态打理（房车设施）**
- 🌾 一键收获全部种植 / 💧 浇水 / 🧪 施肥
- 🐄 一键宰杀全部养殖 / 🥚 孵化 / 🐣 放入全部动物 / 🍖 喂食
- 🍳 一键烹饪全部菜谱 / ✨ 一键全部完成 / 🤖 自动打理（每 15 秒执行一次）

**面板**
- 🔧 小型化（`─` 缩成小标题条 / `▣` 展开，状态记忆，不挡游戏画面）
- 位置拖动记忆；防重复注入（只会有一个面板）

## 🗂️ 存档修改器主要页签

| 页签 | 可改内容 | 生效时机 |
|------|----------|----------|
| 角色/全局 | 源晶、晶核、觉醒天赋点、声望、挂机源晶、重生次数、继承属性 | 局内/局外 |
| 当前局 | 现金、心情、剩余天数、信用分、复活次数、房车/背包等级、幸运 | 局外 |
| P2 战斗 | 生命、攻击、防御、燃料、弹药 | 局外（派生值，建议改角色属性） |
| 物品 | 单件/批量改数量（背包+仓库）；「全部设为 X」任意数值 | 局外 |
| 角色属性 | 等级、经验、属性点、力量/敏捷/体质/感知 | 局外 |
| 装备 | 等级/强化/升级/耐久/稀有度/词缀，解锁神器锻造 | 局外 |
| 卡牌 | 57 种塔防卡牌白/绿/蓝/紫/金数量 | 局内/局外 |
| 命途 | 专精路线、待分配点数、里程碑、命格技能 | 局外 |
| 医疗舱 | 觉醒阶段、经验倍率、克隆年龄、端粒债务 | 局外 |

> 属性点上限 = (等级-1)×2；改超上限游戏会按比例重分配（游戏机制）。
> 生命/攻击/防御是游戏实时重算的派生值，直接改会被覆盖，请改角色属性。
> 改真实楼层进度前建议先点一次「备份存档」。

## 🧰 开发源码说明

- `source/save_editor.cs` 等 C# 源码：用 `编译.bat`（csc / .NET Framework 4.x）一键编译。
- `source/build_mod.js` + `source/rh_src/`：从原版 `app.asar` 解包重打补丁的构建脚本。
  - 生态注入锚点与函数名（宰杀/菜谱等）为**自适应解析**，游戏更新改名也能自动适配；
  - 楼层解锁/还原基于 TowerExploration 组件的 `nodeId(t)` 与 `p2.exploration.towerChapterProgress`。
- `source/cdp_check*.js`：带 `--remote-debugging-port` 启动游戏后，脚本化验证面板/生态/还原路径是否注入成功。

## ⚠️ Steam 版用户注意

修改器直接改本地存档，Steam 云存档校验会发现本地与云端不一致，可能提示「存档被破坏 / 存档冲突」。

- 这**不是存档坏了**，是 Steam 云同步防止第三方修改的机制。
- 解决：修改前关闭「保持此游戏的跨设备同步」，或修改后选择「使用本地并上传」。
- 修改器写入的存档已重算校验和、结构有效，游戏本身能正常读取。
