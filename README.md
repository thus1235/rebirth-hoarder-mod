# 末世：我有一辆房车 —— MOD 工具库 (Rebirth Hoarder Mod & Save Editor)

《末世：我有一辆房车》(Rebirth Hoarder, Steam/Electron, **版本 3.5**) 的第三方单机增强工具：

- **游戏内修改面板**（F8 开关）：战斗秒杀 / 一键解锁楼层 / 跳层 / 强制撤离 / 一键生态打理。
- **存档修改器**（独立 exe）：修改源晶、现金、角色属性、装备、卡牌、命途、医疗舱、物品数量等。

> 仅供个人单机体验，作者：thus。

## ⚙️ 安装（分发包 `mod/`）

### MOD 增强（游戏内 F8 面板）

1. 完全关闭游戏。
2. 双击 `安装MOD.bat`（自动定位游戏目录；找不到时手动输入或把游戏文件夹拖到 bat 图标上）。
3. 启动游戏 → 进废墟探索 → 按 **F8** 打开面板。

**还原原版：** 双击 `还原MOD.bat`。

### 存档修改器

1. 双击 `存档修改器.exe`（游戏开着也能改）。
2. 自动读取存档目录。
3. 修改数值 → 点「写入修改」（写入前自动备份 + 自动重算校验和）。

## 🗂️ 存档修改器主要页签

| 页签 | 可改内容 | 生效时机 |
|------|----------|----------|
| 角色/全局 | 源晶、晶核、觉醒天赋点、声望、挂机源晶、重生次数、继承属性 | 局内/局外 |
| 当前局 | 现金、心情、剩余天数、信用分、复活次数、房车/背包等级、幸运 | 局外 |
| P2 战斗 | 生命、攻击、防御、燃料、弹药 | 局外（派生值，建议改角色属性） |
| 物品 | 单件/批量改数量（背包+仓库）；「全部设为 X」任意数值 | 局外 |
| 角色属性 | 等级、经验、属性点、力量/敏捷/体质/感知 | 局外 |
| 装备 | 等级/强化/升级/耐久/稀有度/词缀，解锁神器锻造 | 局外 |
| 卡牌 | 57 种塔防卡牌白/绿/蓝/紫/金数量 | 局内/局外 |
| 命途 | 专精路线、待分配点数、里程碑、命格技能 | 局外 |
| 医疗舱 | 觉醒阶段、经验倍率、克隆年龄、端粒债务 | 局外 |

> 属性点上限 = (等级-1)×2；改超上限游戏会按比例重分配（游戏机制）。
> 生命/攻击/防御是游戏实时重算的派生值，直接改会被覆盖，请改角色属性。

## 🧰 开发源码说明

- `source/save_editor.cs` 等 C# 源码：用 `编译.bat`（csc / .NET Framework 4.x）一键编译。
- `source/build_mod.js` + `source/rh_src/`：作者构建补丁的脚本，从原版 `app.asar` 解包重打补丁。
- `source/finalize.ps1`：更新后自动清理 + 重建分享包 + 校验。

## ⚠️ Steam 版用户注意

修改器直接改本地存档，Steam 云存档校验会发现本地与云端不一致，可能提示「存档被破坏 / 存档冲突」。

- 这**不是存档坏了**，是 Steam 云同步防止第三方修改的机制。
- 解决：修改前关闭「保持此游戏的跨设备同步」，或修改后选择「使用本地并上传」。
- 修改器写入的存档已重算校验和、结构有效，游戏本身能正常读取。
