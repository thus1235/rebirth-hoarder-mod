## 📥 安装 / 更新 / 还原

### MOD 增强（游戏内 F8 面板）

| 步骤 | 操作 |
|------|------|
| 1 | 完全关闭游戏 |
| 2 | 双击 **`安装MOD.bat`**（自动定位游戏目录；找不到时按提示输入，也可把游戏文件夹拖到 bat 图标上） |
| 3 | 启动游戏 → 进废墟探索 → 按 **F8** 打开面板（再按 F8 或点 ✕ 关闭） |

- **更新**：MOD 已安装时再跑一次 `安装MOD.bat`，几秒钟覆盖补丁，无需先还原。
- **还原原版**：双击 **`还原MOD.bat`**，游戏完全恢复原状，不影响存档。
- **自动适配（v3.21）**：游戏更新后无需等新版 MOD——安装器现场解包并按语义锚点自动适配变量名/文件名变化；若代码大重构导致锚点失效，会安全中止、自动还原原版并生成《MOD适配诊断.txt》（游戏 resources 下），把该文件发给作者即可加快适配。
- **中断恢复**：安装中途断电/关窗，下次双击 `安装MOD.bat` 自动恢复原版并重装。

### 存档修改器

1. 双击 **`存档修改器.exe`**（免安装，单文件；游戏开着也能改）。
2. 自动定位存档目录（`%APPDATA%\Rebirth Hoarder\steam-cloud\saves`），可手动更改。
3. 修改数值 → 点 **「写入修改」**：自动备份 → revision 比对防覆盖 → 重算校验和 →（游戏运行中）自动重载生效。

### 🔍 「添加物品」页（搜索引擎式）

```
支持：中文名 ／ ID ／ 拼音首字母 ／ 模糊输入 ／ 空格分多词
示例：zdylb → 战地医疗包     jtljq → 加特林机枪     加特 机枪 → 加特林机枪     弹箱 → 弹药箱
```

- 按相关度排序（前缀 > 拼音 > 包含 > 模糊子序列），最多显示前 40 条
- **双击条目直接加入**；搜索框回车加入第一个结果，连续补资源不碰鼠标
- 最近添加 10 种自动记忆置顶（`rh_recent_items.txt`）
- 普通物品：数量 + 背包/仓库，同物品自动合并堆叠
- 武器/护甲/饰品：等级(1-99)·强化(0-10)·改造(0-30)·稀有度(普通→神器)，生成全新装备实例；神器自动带来源标记，可进装备工坊锻造体系
- 物品表由 `gen_item_table.js` 构建期从游戏本体 ITEMS 提取（163 种，含类型/堆叠/耐久/图标），与游戏版本自动一致

> 💡 属性点上限 = (等级-1)×2，改超上限游戏会按比例重分配（游戏机制）。
> 💡 生命/攻击/防御是游戏实时重算的派生值，直接改会被覆盖——请改「角色属性」页。

## ⚠️ Steam 云存档注意

修改器直接改本地存档，Steam 云同步可能提示「存档冲突/被破坏」——**这不是存档坏了**，是云同步防第三方修改的机制。

- 方法①：Steam → 库 → 右键游戏 → 属性 → 通用 → 取消勾选「保持此游戏的跨设备同步」
- 方法②：弹出冲突时选「使用本地并上传」，用改好的本地档覆盖云端
- 修改器写入的存档已重算校验和、结构有效，游戏本身能正常读取
